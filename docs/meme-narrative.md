# 迷因敘事（按需）

Grook 在 LINE 群組被 **@** 且訊息含意圖關鍵字時，產出「敘事型迷因」調研報告。

## 觸發

- 需先被 @Grook（或 bot 顯示名）
- 且文字含（不分大小寫）：`迷因`／`敘事`／`meme`／`narrative`
- **沒有**上述關鍵字 → 走原本的 X 時間軸／跟隨通知整理

## 不做

- 不排程自動推迷因日報到 LINE
- 不接錢包私鑰／交易 API
- 不以違規爬蟲當預設資料來源

## 篩選三步

1. 各鏈交易量排名（鏈比鏈，含可得的 Robinhood 等）— 不是每鏈幣 Top5
2. 高量鏈上的**新池**熱點 — 不是常青榜 Top5
3. 敘事硬過濾：文化／梗先於幣、討論能續、有二創；剔一波流／純刷量／純熱榜 boost／分身農場／純 KOL

參考錨點：PEPE、dogwifhat、Neiro、哈基米、牛來。嚴篩、寧缺勿濫。

## 報告格式（繁中）

1. 標準一句
2. 通過候選 0–5
3. 剔除雜訊
4. 免責

## 與 Grok Bot 的關係

Grok Bot 另有排程迷因日報；本路徑是 **LINE 按需交付**，規格同源、通道分開。

## 實作狀態

- `MEME_PROVIDER=mock`（預設）：本機假候選，用來測意圖分流與報告格式
- `MEME_PROVIDER=live`：打 DexScreener 等公開 HTTPS；敘事判斷仍偏保守，常回空報告並說明原因
